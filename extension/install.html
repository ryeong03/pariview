개발·시연용 ZIP으로 직접 설치할 때
  1. 받은 pariview-extension.zip의 압축을 풀고 폴더를 보관해주세요
  2. 크롬 주소창에 chrome://extensions를 입력하고 오른쪽 위 개발자 모드를 켜주세요
  3. 압축해제된 확장 프로그램을 로드합니다를 눌러 manifest.json이 들어 있는 pariview-extension 폴더를 선택해주세요
  4. 크롬 도구 모음의 확장 프로그램 메뉴에서 PariView를 고정해주세요

설정을 가져올 때

  1. PariView 열기 → 이미 열려 있었다면 새로고침해주세요
  2. 직접 설정하거나 추천을 비교한 뒤 설정을 저장해주세요 임시 미리보기는 다른 영상에 전달되지 않아요
  3. 유튜브를 새로 열거나 새로고침하고 영상을 재생해주세요 소리 효과는 영상 페이지를 한 번 누른 뒤 시작돼요
  4. PariView 아이콘을 누르면 현재 탭의 적용 상태를 확인할 수 있어요
끄려면 팝업에서 다른 영상에도 적용하기를 꺼주세요 영상 위치·재생 속도·플레이어 음량·음소거는 바꾸지 않고 화면 필터와 소리 효과를 해제해요

어디까지 적용되나요

화면 밝기·대비·채도·따뜻함과 지원되는 영상의 음량·높은 소리 완화·음량 변화 완화·말소리 대역 강조가 적용돼요

음량 35%는 영상 플레이어의 원래 음량에 0.35를 곱하는 설정이에요 플레이어가 음소거 중이면 확장 프로그램이 음소거를 해제하지 않아요

보호된 영상이나 소리 접근을 허용하지 않는 영상에서는 화면만 조절하고 원본 소리를 유지해요 장면 안내·자막·영상 요약·AI 분석·자동 밝기 보정은 유튜브에서 제공하지 않아요
