이 자료의 용도

신경다양성 당사자 성인 10명에게 제공할 실험·설문 서식이에요
이미 진행했다고 사용자가 확인한 당사자 검증과는 별도의 문서예요
여기에는 실제 참여자의 응답이나 평가 결과를 넣지 않았어요

확인할 질문

  1. 같은 장면에서 기본 설정과 개인 설정의 시청 편안함은 어떻게 다른가요?
  2. 참여자는 피팅을 직접 완료하고, 설정을 바꾸거나 되돌릴 수 있나요?
  3. 어느 화면이나 조작에서 개선이 필요한가요?

대상과 운영

  • 만 19세 이상, 본인을 신경다양성 당사자로 설명하는 성인 10명
  • 당사자 여부는 자기보고로 확인하고 진단명·진단서·복약 정보는 받지 않아요
  • 한국어 안내와 문항에 본인의 의사를 표현할 수 있는 분을 모집해요
    평소 쓰는 보조기기, 글로 답하기, 동행 지원을 사용할 수 있어요
  • 1명씩 약 20–25분, 휴식은 필요에 따라 더해요
  • 10명 모집은 이번 점검의 운영 규모예요 대상 전체의 효과를 추정하는 검정력 계산에서 정한 수가 아니에요

  5. 실험 도중 새 탭을 열거나 버전을 바꾸지 않아요 각 참여자의 A·B 설정 파일을 ID로 보관해요

진행자가 읽을 안내와 기록

“화면과 소리를 직접 설정해 보고, 두 설정으로 같은 장면을 볼 거예요 어느 쪽이 더 편한지, 차이가 없는지 모두 알려주세요 정답은 없어요 불편하면 바로 멈추거나 쉬어도 돼요 원하지 않는 질문은 넘어갈 수 있어요”

피팅 과제

“직접 설정하기에서 오늘의 시작 모드를 고르고, 비교 화면을 따라 설정을 적용해 주세요 비슷해요와 건너뛰기도 사용할 수 있어요”

진행자는 답을 추천하지 않아요 도움을 요청하면 먼저 문장을 같은 뜻으로 다시 읽고, 버튼 위치를 알려주거나 대신 클릭했으면 도움 내용을 기록해요

완료 상태를 이렇게 구분해요

상태기록 기준
unaided단계나 버튼을 가리키는 도움 없이 본인이 설정 적용까지 완료했어요
assisted진행자의 조작 안내 또는 대리 클릭을 받고 완료했어요
not_completed시도했지만 설정 적용까지 완료하지 않았어요
not_attempted피팅을 시작하지 않았어요

평소 쓰는 보조기기·읽기 지원은 사용할 수 있어요 사용한 지원을 기록하고, 피팅 조작 자체를 도운 경우와 구분해요 시간은 경쟁 기준으로 안내하지 않아요

중단·휴식

  • 참여자가 멈춤·휴식을 요청하거나 불편을 표현하면 영상을 바로 멈춰요 이유 설명을 요구하지 않아요
  • 중단한 조건, 시청한 초, 이후 응답을 남길지 여부를 기록해요 중단 점수를 0점으로 채우지 않아요
  • 두 조건의 같은 구간을 다 보지 못한 경우에는 완전한 A–B 점수 비교에서 제외하고 중단 사례로 별도 보고해요
  • 현재 영상을 보기 어렵거나 의료진에게 시청을 제한하라는 안내를 받은 분은 영상 비교 대신 화면 조작 의견만 남길 수 있어요

연구 기록

참여자 번호, 사용 버전·기기, 실제 순서, 도움 여부, 피팅 시간, A·B 설정 파일, 조건별 응답, 중단·절차 이탈을 기록해요
