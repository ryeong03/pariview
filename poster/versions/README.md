최신 작업본은 `poster/PariView_A1.html`이고, 이전 버전 폴더에는 html·pdf·preview를 보관해요

PDF와 preview는 해당 시점의 출력본이에요 v1~v4와 v6의 HTML은 표에 적힌 커밋의 원문이므로, 해당 커밋의 assets와 web/dist를 함께 사용해 재현해요

v5는 별도 커밋 전에 보존한 버전이며, HTML의 리소스 경로만 보존 폴더 위치에 맞췄어요 저장소 루트에서 아래 명령을 실행하면 v5 폴더에 PDF와 PNG를 다시 출력해요

```sh
uv run --with playwright python poster/render.py poster/versions/v5/PariView_A1.html
```
