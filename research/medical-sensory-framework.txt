PariView 추가 조사: 안과·이비인후과/청각학·정신건강의학과의 평가 체계
확인일: 2026-11-04
출처별 정확한 서지·DOI·확인 수준은 medical-sensory-sources.json.
앞선 literature-review.txt의 개인차·통제권 근거를 보완하는 보고서다. 임상지침, 전문가 합의, 개념모형, 치료시험을 구분했다.

결론
세 분야의 ‘무엇을 따로 살펴보는가’와 ‘사용자 응답으로 미세조정하는 과정’을 참고할 수 있다. PariView의 목적에는 시청 선호를 찾는 피팅이 적합하다. 치료기법의 이름을 가져와 의료효과가 있는 앱처럼 제시할 근거는 없다.
추천 설명: “시각·청각 평가의 비교 절차와 개인별 감각 환경 조정 원칙을 참고해, 지금 나에게 편안한 시청 설정을 찾아가는 경험을 제안한다.”
이 결합 구조는 PariView의 설계 해석이며, 세 진료과가 공동 검증한 통합 검사 체계라는 뜻이 아니다. 광과민·청각과민·정서반응의 원인은 여러 분야에 걸칠 수 있으므로 진료과별로 사용자를 배타적으로 나누지 않는다.

1. 안과/검안: 선명도와 편안함을 나눠 보기 [M1, M2]
근거: 자각적 굴절검사는 환자의 반응을 참고해 굴절교정을 정밀하게 조정한다. 시각 평가에는 시력 이외에도 대비감도·눈부심과 관련한 검사가 있다.
가져올 부분: 같은 장면을 두 설정으로 비교하고 한 번에 하나의 조절 축을 바꾸는 절차. ‘대사가/글자가 더 잘 보이는가’와 ‘화면이 더 편안한가’를 다른 질문으로 둔다.
후보 조절 축(제품 제안): 전체 밝기, 밝은 부분, 대비, 색감. 급격한 밝기 변화·깜박임·움직임은 별도 콘텐츠 특성으로 취급한다.
의료와의 경계: 굴절검사는 주로 시력 교정값을 구하는 과정이지 시청 감각 선호 검사 자체가 아니다. 화면 A/B로 시력·안질환·광과민 역치를 판정할 수 없다. 화면 밝기 %를 검사실의 광량 측정치처럼 쓰지 않는다.
예시 질문: “어느 쪽이 보기 편한가요?” / 별도 확인: “자막과 어두운 장면이 여전히 잘 보이나요?”
‘안경 맞추듯 비교한다’는 절차 비유는 가능하지만 안과 처방을 대체한다는 표현은 피한다.

2. 이비인후과/청각학: 듣는 능력과 소리 내성을 구분 [M3, M4]
근거: 청각과민(hyperacusis), 특정 소리의 패턴·의미에 대한 반응(misophonia), 소리에 대한 두려움(phonophobia)은 구분해 다룬다. 서로 겹칠 수 있어 문답 몇 개로 진단명 중 하나를 자동 선택할 수 없다.
특히 미소포니아 합의 정의는 반응을 단순 음량으로 설명하지 않고, 소리의 특징·맥락·통제감 등을 함께 고려한다.
가져올 부분: “전체가 커서 불편함 / 갑작스러운 변화 / 특정 소리 / 대사 식별 어려움”을 별개 필요로 수집한다. 전체 볼륨 감소만으로 모든 문제를 해결한다고 가정하지 않는다.
검사 참고: LDL/ULL(불쾌음량 수준)이라는 임상 평가가 있지만, ASHA도 변동성·검사 어려움과 개인별 해석을 설명한다.
제품 경계: 앱에서 소리를 계속 키워 ‘얼마나 참는지’를 측정하지 않는다. 일반 이어폰·스피커의 볼륨 %는 임상 dB HL/SPL과 동일하지 않다. PariView는 편안한 수준 내 선호 비교와 원본 복귀를 제공하는 설계다.

3. 정신건강의학/임상심리: 자극의 크기와 주의·긴장·생활 영향을 구분 [M5, M6]
근거: NICE 성인 자폐 지침은 감각 필요에 맞춘 빛·소리 환경 조정, 휴식, 예측 가능성을 고려한다. NIMH의 RDoC는 주의·정서·각성조절 등 기능 차원을 다루는 연구틀이며 진단 도구가 아니라고 명시한다.
가져올 부분: 현재 피로·긴장·주의 유지의 어려움과 사용자가 원하는 도움을 짧게 묻고, 오늘의 설정을 다시 조정할 수 있게 한다. 상태 질문은 선택사항으로 둔다.
제품 제안: “오늘은 소리 변화가 더 거슬려요”, “대사를 놓치기 쉬워요”, “사전 안내를 받고 싶어요”처럼 필요를 표현한다.
경계: 답변으로 ADHD·자폐·불안장애를 추정하거나 정신건강 점수를 만들지 않는다. ‘뇌의 감각 역치’, ‘각성 정상화’처럼 생리적 측정을 한 듯한 표현을 쓰지 않는다.

4. 감각 ‘분류’ 자체에 유용한 보완 틀: Dunn 모델 [M7]
감각추구(sensory seeking), 감각회피(sensory avoiding), 감각민감(sensory sensitivity), 낮은등록(low registration)의 네 패턴을 제안한다. 개념상 자극 역치와 자기조절 전략을 함께 본다.
이는 작업치료 기반 모델이다. 정신과의 공인 4유형 진단표가 아니며, 한 사람이 모든 감각에서 하나의 유형에만 속한다고 강제할 이유도 없다.
제품 연결: 자극 감소만이 답이라는 가정을 피하고, ‘덜 자극적 / 원본 유지 / 정보가 더 또렷하게’를 사용자가 필요에 따라 고르게 한다.
한계: A/B 선호 선택을 신경학적 역치 측정으로 간주하지 않는다. 기존 Sensory Profile 척도를 구현하거나 검증한 것처럼 이름 붙이지 않는다.

5. 치료기법은 무엇이 있고, 어디까지 참고할 수 있는가
안과: 원인 질환의 평가·치료와 굴절교정이 기본 맥락이다. 특정 착색렌즈의 임상 연구도 있다.
- Blackburn et al. (2009) [M8]: 안검경련 환자30명의 렌즈 교차시험, 별도 환자26명/대조26명의 비교에서 FL-41 렌즈를 평가했다. 대상 질환·렌즈 광학 특성이 정해진 연구다.
- 한계: CSS 색 필터나 화면을 분홍색으로 만드는 것이 FL-41 렌즈와 동일하다는 근거가 아니다. 자폐·ADHD·일반 시청자에게 그대로 효과를 일반화할 수 없다.

청각과민: 교육·상담, CBT, 소리치료 등이 임상적으로 사용·연구된다. 치료 선택과 자극 변화는 전문가가 환자별로 판단할 영역이다. [M3]
- Jüris et al. (2014) [M9]: 환자60명 CBT 대기군 비교. LDL 등은 차이가 있었지만 불안 척도는 유의한 집단 차이가 없었다.
- 한계: 대기군은 적극적인 다른 치료가 아니다. 단순 볼륨 완화·A/B 피팅·백색소음 재생의 효과를 입증하지 않는다.

미소포니아: 정신건강의학과 기반의 CBT 무작위시험이 있다.
- Jager et al. (2021; 온라인2020) [M10]: 환자54명, 3개월 주간 집단치료/대기군 비교. 주의집중 훈련·각성 감소·정서 관련 요소·자극 조작을 묶은 치료에서 증상 개선을 보고했다.
- 한계: 단일 전문기관의 묶음 치료 연구다. 호흡 버튼·알림·필터 한 가지에 치료효과를 이전할 수 없다. 사용자에게 무작정 자극을 견디거나 점차 강하게 노출시키는 기능의 근거가 아니다.

명칭 주의: ‘감각통합치료’, ‘청각통합훈련’, ‘소리치료’는 같은 뜻이 아니다. NICE는 자폐 아동·청소년의 말·언어 문제에 대한 청각통합훈련(AIT)을 권고하지 않는다. [M11] ‘감각통합 치료 기반’이라는 포괄적 홍보문구는 사용하지 않는 편이 정확하다.

6. PariView에 적합한 구현 분류(연구를 참고한 자체 설계안)
입력1: 어떤 특징인가 — 화면 밝기/대비/급변, 전체 음량/갑작스러운 소리/특정 소리, 대사·자막 가독성.
입력2: 어떤 경험인가 — 불편하다, 놀란다, 산만해진다, 잘 알아듣기 어렵다, 괜찮다.
입력3: 지금의 맥락 — 피로·긴장·주변 환경·사용 기기(원할 때만 입력).
입력4: 무엇을 원하는가 — 더 부드럽게, 원본 그대로, 정보를 더 또렷하게, 사전 안내, 잠깐 쉬기.
출력: 사용자가 고른 설정값과 다시 조정할 수 있는 선택지. 진단·심각도·정상/비정상 판정은 출력하지 않는다.
기존 다섯 프로필은 편집 가능한 ‘시작 설정’으로 사용한다. 의학적으로 확립된 다섯 감각 유형이라고 설명하지 않는다.

A/B 피팅 권장 절차(임상 검사를 재현한 것이 아님)
현재 기기·사용자가 편안하게 선택한 수준에서 시작 → 같은 장면/같은 대사를 비교 → 한 번에 하나의 설정 차이 → A/B/차이 없음/건너뛰기 → 전체 장면에서 가독성·이해 여부 다시 확인 → 사용자가 저장.
선택 횟수나 확신도는 선호 응답 기록일 뿐, 임상적 정확도·치료 반응률로 제시하지 않는다. 원본 복귀와 재피팅을 유지한다.

포스터용 짧은 문구
“안경을 맞추듯 비교하고, 오늘의 감각에 맞게 다시 조절합니다.”
근거 설명: “자각적 비교 절차, 소리 내성의 개인차, 감각 환경 조정 지침을 참고한 시청 선호 탐색.”
주석: “의학적 진단·처방·치료가 아닌 인터페이스 설계 제안.”
