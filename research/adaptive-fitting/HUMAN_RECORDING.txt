적응형 피팅 비교 기록 서식 — 미작성

이 자료는 새 알고리즘 비교를 기록하기 위한 제공용 양식이다
기존 당사자 참여 검증은 사용자가 완료를 확인했으며, 비교별 수치는 기록하지 않았다고 설명했다
아래 절차가 기존 검증에서 수행된 것으로 연결하지 않는다

목적과 모집
적응형 / 고정 질문 방식을 같은 조건에서 비교해 선호 설정, 부담, 시간 차이를 기록한다
성인 신경다양성 당사자 자기보고 기준, 추가 수집 시 10명 규모의 사용성 파일럿에 활용 가능
10명은 이 서식의 운영 예시이며 기존 참여 검증 인원으로 확정하지 않는다
동의 후 익명 코드 P01–P10 사용, 연락처·진단 문서는 이 CSV에 넣지 않는다
자유롭게 건너뛰거나 중단 가능, 같은 금액의 사례비 원칙

운영 1 — 조건 고정
같은 기기·화면·헤드폰·시스템 음량·자리·평가 클립·구간·속도를 사용
피팅의 세 숫자 축 외 설정은 두 방식에서 동일하게 유지
압축·고음 필터·말소리 EQ·색감·자막·예고 상태를 운영 기록에 적고 비교 중 고정
장면마다 설정 변경과 자동 밝기 보정은 꺼서 비교 값이 덮어써지지 않게 함
‘원본 비교’와 앱의 ‘기본값으로 초기화’는 서로 다른 조건이므로 혼용하지 않음
동일 시작 숫자값 밝기85·대비90·음량35에서 두 방식을 각각 시작
소리 비교는 참가자가 낮은 후보부터 재생, 양쪽은 같은 구간을 비교

운영 2 — 순서 교차
10명 운영 예시: P01–P05 adaptive→fixed, P06–P10 fixed→adaptive
방식 이름은 참가자에게 X/Y로 표시하고 결과 설명도 동일하게 제공
각 방식은 5회 확정 응답까지만 수집, 추가 비교는 주 평가 이후 별도 세션으로 기록
적응형과 고정 방식 모두 같은 엔진·posterior 추정기를 쓰고 query policy만 다르게 함
매 질문에서 제시값·선택·누적 추정값을 보존, 단계0 시작값도 저장
equal/unsure/skip과 중단은 실제 상태 그대로 보존, 숫자로 임의 치환하지 않음
두 방식 사이에는 쉬는 시간을 제공하고 기존 선택값을 보여주지 않은 채 시작값 복원

운영 3 — 독립 참조값 3회
두 방식 비교와 분리하여 같은 클립·구간에서 직접 슬라이더로 편한 값을 3회 조절
각 회 시작 위치를 바꾸고 앞선 설정값을 가려 기억에 따른 복제를 줄임
원하면 ‘비슷하게 괜찮은 범위’를 함께 메모하고 세 값의 변동을 보고
3회 중앙값은 참조값으로 쓰되 사람의 고정된 정답이나 감각 역치로 부르지 않음
실험 후 참조값을 수집하면 학습·순서 영향이 남는다는 점을 결과 해석에 기록

짧은 질문(각 방식 종료 후)
1 지금 고른 설정으로 같은 장면을 볼 때 얼마나 편한가요? 0 전혀 편하지 않음 – 10 매우 편함
2 비교하고 고르는 과정은 얼마나 부담스러웠나요? 0 전혀 부담 없음 – 10 매우 부담스러움
3 더 비교하고 싶나요? 지금 설정으로 보기 / 조금 더 비교하기 / 잘 모르겠음
4 무엇이 달라졌거나 어려웠나요? 자유 응답
두 방식 후: 어느 설정으로 보고 싶나요? X / Y / 비슷함 / 잘 모르겠음
질문 답변은 별도 운영 기록에 보존하며 수치 오차 CSV와 다른 결과로 분석

파일 사용
human-trials-template.csv: 익명 코드·방식·0~5회 추정값·실제 후보·응답
human-reference-template.csv: 같은 익명 코드의 독립 참조 조절 1~3회
import_snapshot.py: 엔진 snapshot을 trial CSV로 변환, 실제 참여 기록이 있을 때만 사용
analyze_human.py: 두 방식0~5회 및 참조3회가 모두 있는 사례의 참조값 거리를 계산
빈 서식에서는 observed_n=0만 반환하고 사람 결과 그래프를 생성하지 않는다
부분 기록을 정답이나 완료값으로 채우지 않는다
실제 자료는 private/ 아래에 보관하며 Git 추적에서 제외한다

그래프 라벨
‘반복 참조 설정과의 정규화 거리’ / ‘A/B 비교 횟수’ / ‘실제 기록 n=...’
합성 그래프의 알려진 θ 오차와 구분한다
각 방식의 편안함·부담 점수, 중단·누락 수, 참조값 변동을 함께 제시한다
10명 파일럿의 평균으로 모든 신경다양성 이용자나 임상 효과를 일반화하지 않는다
